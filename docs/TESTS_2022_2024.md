- 2024 : anomalie `P104.3_REPORTED_RT` conservée en audit.

## Exécuter les tests

```powershell
py -m unittest discover -s tests -v
```

La suite vérifie les certifications historiques, le caractère bloquant d'une anomalie en production et le caractère non bloquant de la même anomalie en audit.

Pour reproduire une consolidation hors ligne :

```powershell
py update_observatoire.py --year 2022
py update_observatoire.py --year 2023
py update_observatoire.py --year 2024
```

Les anciens résultats certifiés sont conservés dans `modules/orchestrator/outputs/certif_YYYY/` ; les nouvelles exécutions vont dans `annual_YYYY/` et ne les écrasent pas.
